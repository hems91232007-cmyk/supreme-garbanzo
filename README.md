
Campus App – UI/UX Research and Prototype

Project By: Hemavarni

📌 Project Overview

The Campus App is a mobile application concept designed to improve communication and make campus activities easier for students and faculty. This project focuses on UI/UX research, user-friendly interface design, and interactive prototyping to create a smooth and efficient campus experience.

🎯 Objectives

- Understand the needs and challenges faced by students on campus.
- Conduct UI/UX research to identify user requirements.
- Design a simple, attractive, and user-friendly interface.
- Create wireframes and high-fidelity UI screens.
- Develop an interactive prototype to demonstrate the app's workflow.
- Improve usability and accessibility through user-centered design.

🔍 Research Process

1. User Research: Identify student needs, expectations, and common campus-related problems.
2. Problem Identification: Understand challenges such as accessing campus information, checking timetables, and receiving announcements.
3. User Personas: Define the target users and their goals.
4. Information Architecture: Organize the app's features and navigation.
5. Wireframing: Create basic layouts for the main screens.
6. UI Design: Develop the visual interface with suitable colors, typography, and components.
7. Prototyping: Connect the screens to demonstrate user interactions and navigation.
8. Usability Testing: Gather feedback and identify areas for improvement.

📱 Key Features

- Student login and registration
- Student dashboard
- Class timetable and schedule
- Campus announcements and notifications
- Events and activities
- Attendance information
- Academic information
- Profile and settings

🛠️ Tools Used

- Figma – UI design, wireframing, and interactive prototyping
- Google Forms – User surveys and research (if used)
- FigJam – User flows and brainstorming (if used)

🎨 Design Approach

The design follows a user-centered approach, focusing on simplicity, consistency, accessibility, and easy navigation. The interface aims to help students find important campus information quickly while providing a clear and engaging user experience.

📂 Project Deliverables

- User research and findings
- User personas
- User flow diagrams
- Low-fidelity wireframes
- High-fidelity UI screens
- Interactive prototype
- Usability feedback and design improvements

🚀 Expected Outcome

The final outcome is a user-friendly campus app prototype that demonstrates how students can access essential campus services and information through a simple, organized, and intuitive interface.
